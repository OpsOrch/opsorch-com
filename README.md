# OpsOrch.com

The public website and documentation hub for OpsOrch.

## Scope

This app publishes:
- Product overview and architecture pages
- Quick start and component docs
- Licensing and contribution guidance
- Links to the open-source repos under the OpsOrch org

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm start
```
